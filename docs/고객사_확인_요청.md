# 고객사 확인 요청 목록

2026-11-25 「추가자료」 반영 후 기준입니다. 홈페이지 내용은 모두 고객사 자료에서 가져왔고, 아래는 공개 전에 고객사 확인이 필요한 항목입니다.

- 「2026 07 회사 제품 소개」, 회사 팜플렛, 대표논문 리스트, 이연희 공적서, 언론 보도 정리, 홈페이지 회의록

## 2. 아직 확인이 필요한 항목

### 보유 균주 수치 (메인·회사 개요·보유 기술)
회사 제품 소개서와 현재 홈페이지가 일치하는 「약 3,000주 · 12개 속」, 「GRAS 유산균 19종」만 남겼습니다. 아래 두 가지는 확인 전까지 뺐습니다.
- **400**: 소개서는 「400스트레인 이상의 GRAS」, 현재 홈페이지는 「감수성 균주 약 400 strain」으로 의미가 다릅니다.
- **14,000 내성균주 (72속 192종)**: 소개서에서 항생제내성균주은행(CCARM) 항목에 있는 수치입니다. 피엘비앤비 보유 자산으로 표기해도 되는지 확인이 필요합니다.
- 소개서의 「3000종 이상」은 현재 홈페이지의 「약 3000 strain」에 맞춰 「약 3,000주」로 적었습니다.

출원 4건은 증빙을 보지 못했습니다. 출원 사실 증명원을 주시면 확인하겠습니다.

### 특허 10-1452234 를 비공개로 돌렸습니다
지난번에는 특허증이 있어 게시했지만, 이번에 「홈피」용으로 정리해 주신 특허증 16건에 들어 있지 않고 특허권자가 (주)피엘바이오로 되어 있어 비공개로 바꿨습니다. 게시를 원하시면 `data/patents.json` 에서 해당 항목의 `published` 줄을 지우면 됩니다.

### 특허권자가 (주)피엘바이오로 표기된 특허
0449597(헬리코박터), 0532362(비피도박테리움 인판티스)는 특허증에 특허권자가 (주)피엘바이오로 적혀 있어 상세페이지에 그대로 표시했습니다. 10-0686557, 10-0686558, 10-0962052 는 특허증 1쪽에 「등록사항란에 기재」로만 되어 있어 특허권자를 표시하지 않았습니다. 현재 권리자가 피엘비앤비로 바뀌었다면 알려 주세요.

### 공개 여부
- **협력사 로고와 제품 사진.** 고객사 현재 홈페이지에 올라와 있는 파일을 그대로 가져왔습니다. 각 회사의 상표와 제품 사진이므로 사용 허락 여부를 확인해 주세요. 종근당건강, 노바렉스, 콜마, 코리아나화장품은 로고가 없어 글자로 표시합니다.
- **쎌바이오텍, 메디오젠, 바이텍, 피엘바이오.** 현재 홈페이지에 로고만 있고 협력 내용이 없어 「협력사」로만 표시했습니다. 협력 분야와 내용을 알려 주시면 넣겠습니다.
- **지면 기사 미리보기 13건.** 신문 기사 스캔은 언론사 저작물이라 본문을 읽을 수 없는 작은 크기(가로 360px)로만 넣었습니다. 크게 싣려면 언론사 이용 허락이 필요합니다.
- **특허증 이미지 16건.** 1쪽만 게시했습니다. 0449597 은 발명자 주민등록번호와 자택 주소가, 10-1335454·1335455·1335456 은 발명자 자택 주소가 1쪽에 인쇄되어 있어 **가림 처리**했습니다.
- **대표이사 사진, 행사 사진 8장.** 다른 사람의 얼굴이 함께 나오는 사진이 있습니다.
- **「국내 유일 자체 개발한 한국 토종 유산균」.** 현재 홈페이지에 있는 문구지만 표시·광고 기준상 근거가 필요한 표현이라 넣지 않았습니다. 「BSL2 실험실 보유」는 사실 기재로 보아 넣었습니다.
- **균주 연구 내용의 표현.** 건강기능식품 표시·광고 기준에 맞는지 최종 검토가 필요합니다.

### 내용 확인
- **락토포유.** 현재 홈페이지에 「첫 개발 제품 출시」로 올라와 있어 자체 개발 제품으로 넣었습니다. 판매처와 제품 설명은 받은 자료가 없습니다.
- **SBS 일요특선 다큐멘터리.** 폴더명의 날짜(2020-07-20)를 보도일로 넣었습니다. 방송일이 맞는지 확인해 주세요. 영상 파일(1.8GB)은 홈페이지에 올리지 않았습니다.
- **대만 수출(Priority Healthfood Corporation).** 시기와 규모는 자료가 없어 쓰지 않았습니다.
- **보령제약 / 보령수앤수.** 협력사는 「보령제약」으로, 2015년 출시 제품의 회사는 보도대로 「보령수앤수」로 적었습니다.
- **「콜마」의 정확한 법인명.**

### 승인이 필요한 초안
- 스토리 본문 (`data/company.json`). 대표이사 인사말은 전달받은 문안으로 교체 완료
- 주요 연구 분야·보유 기술·협력 분야 설명 (`src/pages/business.mjs`). 협력 분야 5가지는 항목별로 실제 제공 여부를 확인해 주세요.
- 공지사항 1건, 메인 문구
