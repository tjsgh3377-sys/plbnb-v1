## 2. 공개해도 되는지 확인이 필요한 항목

- **적용 제품과 협력사.** 회사 소개서의 「적용제품」에 적힌 기업·제품명을 그대로 사용했습니다. 남양유업(불가리스, 불가리스 핏), 종근당건강(락토핏), 보령(장수 유산균), 코리아나화장품, 노바렉스, 콜마, 뉴트리, CJ웰케어, 엠테라파마. 각 회사가 공개에 동의했는지, 현재도 적용 중인지 확인이 필요합니다. 「콜마」와 「보령」은 정확한 법인명도 확인해 주세요.
- **협력사 로고와 제품 이미지.** 사용 허가를 받은 파일이 없어 넣지 않았습니다. 현재는 기업명 글자와 「이미지 준비 중」 자리로 표시됩니다.
- **특허증 이미지.** 2건(10-2973622, 10-1452234)의 1쪽만 게시했습니다. 2쪽에는 발명자의 자택 주소가 있어 제외했습니다. 나머지 특허증도 받으면 같은 방식으로 추가할 수 있습니다.
- **대표이사 사진.** 스튜디오 촬영 사진(`182A3093.JPG`)을 사용했습니다. 기존 B안의 `ceo.jpg`(흰 가운, 실험실 배경)는 합성 또는 AI 생성 여부를 알 수 없어 제외했습니다.
- **스토리 페이지의 행사 사진 6장.** ISO 회의, ANRRC 발표, 탄자니아 연구소재은행, 워크숍, 전시회 사진입니다. 다른 사람의 얼굴이 함께 나오므로 게시 가능 여부와 사진 설명(행사명·연도)을 확인해 주세요.
- **균주 연구 내용의 표현.** 논문과 특허에 적힌 범위(세포·동물·인체 연구 단계)를 넘지 않도록 썼고, 균주마다 「완제품의 효능과 구분된다」는 안내를 붙였습니다. 건강기능식품 표시·광고 기준에 맞는지 최종 검토가 필요합니다.
- **이전 법인((주)피엘바이오) 시기의 특허.** 체지방 관련 10-0686557, 여드름 화장료 10-0962052, 항알레르기 10-0507417 등은 현재 권리 관계를 확인할 수 없어 게시하지 않았습니다.

## 3. 초안으로 작성해 승인이 필요한 글

- **대표이사 인사말** (`data/company.json` → `ceo.greeting`). 기존 인사말에 있던 「국내 유일」 같은 확인되지 않은 표현을 빼고 새로 썼습니다. 대표님 명의로 나가는 글이므로 직접 검토가 필요합니다.
- **스토리 본문** (`data/company.json` → `story`). 공적서와 논문 리스트의 사실만으로 구성했습니다.
- **주요 연구 분야, 보유 기술, 협력 분야의 설명 문구** (`src/pages/business.mjs`). 협력 분야 5가지는 실제로 제공하는 서비스인지 항목별 확인이 필요합니다.
- **공지사항 1건** (홈페이지 리뉴얼 안내).
- **메인 문구.** 요청서의 예시 문구를 그대로 사용했습니다.

## 4. 기존 B안에서 삭제한 내용

근거 자료를 찾지 못해 뺐습니다. 사실이라면 근거와 함께 알려 주세요.

- 「협력사 100+」, 「산업화 제품 30+」, 「특허 20+」 등 수치
- 「국내 유일」, 「국내 최고 수준」, 「세계 건강을 선도」 같은 표현
- 「BSL2 수준 실험실」, 「KFDA 인정 균주보관시설」, 「GMP 준수」
- 공지사항 8건 (채용 공고, 국제 특허 확보, 회사 이전 등 실제 사실이 아닌 예시 글)
- 산업 분야 중 「음료」, 「동물사료」
- 오시는 길의 대중교통 안내(「인천메트로 1호선 토평역」)와 팩스 번호 표기, 잘못된 지도 주소
- 균주별 효능 한 줄 설명 (「항산화 기능」, 「비타민 생성」 등 출처 없는 표기)

## 6. 촬영이 필요한 사진

현재 서브 비주얼과 본문 이미지는 메인 영상(DNA, 분자)의 장면을 잘라 쓰고 있습니다. 아래 사진을 촬영하면 교체할 수 있습니다.

| 사진 | 쓰이는 곳 | 권장 규격 |
| --- | --- | --- |
| 연구소 전경, 실험실 내부 | 회사소개 서브 비주얼, 회사 개요 | 가로 1920px 이상 |
| 균주 보존 설비, 배양 장면 | 사업소개 서브 비주얼, 보유 기술 | 가로 1920px 이상 |
| 연구 장면 (실험, 분석 장비) | 개발현황 서브 비주얼, 주요 연구 분야 | 가로 1920px 이상 |
| 대표이사 업무·연구 장면 | 메인 「연구자 스토리」, 스토리 페이지 | 세로형 4:5 |
| 회의·협업 장면 | 협력사 서브 비주얼 | 가로 1920px 이상 |
| 사옥 외관, 출입구 | 오시는 길 | 가로 1200px 이상 |
| 적용 제품 실물 (각 사 허가 후) | 적용 제품 | 정사각형, 흰 배경 |

실제 연구소나 인물을 AI로 생성한 이미지는 사용하지 않았습니다.

## 7. 파비콘

브라우저 탭에 보이는 작은 아이콘은 정사각형이어야 해서 로고의 「PL」 부분만 잘라 만들었습니다. 로고를 변형하지 않는다는 원칙의 예외이므로 고객사 승인이 필요합니다. 로고 매뉴얼에 정사각형 심벌이 있으면 그 파일로 교체하겠습니다.
