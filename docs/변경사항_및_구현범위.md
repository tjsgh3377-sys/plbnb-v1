## 3. 구현한 기능

- **콘텐츠 연결.** 균주·특허·적용 제품·연구 성과·언론 보도·칼럼·협력 사례를 고유 id로 연결합니다. 다대다 연결을 지원하고, 한쪽에만 적어도 양쪽 상세페이지에 나타납니다. 비공개·삭제된 항목은 연결에서 자동으로 빠집니다.
- **균주 정보.** 균주명 검색, 분류 필터, 연구 분야 필터. 다른 페이지에서 `?field=` 주소로 넘어오면 필터가 미리 적용됩니다.
- **특허 현황.** 전체/등록/출원 탭, 특허명·번호·관련 균주 검색. 번호는 하이픈 없이 입력해도 찾습니다. 특허증 확대 보기.
- **게시판.** 검색, 페이지 나누기(10건), 상단 고정, 첨부파일 표시, 이전 글·다음 글.
- **메인 연구 소식.** 게시판의 최신 글이 자동으로 나옵니다.
- **문의 양식.** 필수 항목, 이메일 형식, 개인정보 동의 확인. 오류는 항목 바로 아래에 표시하고 첫 오류 칸으로 초점을 옮깁니다. 문의 유형을 주소로 미리 지정할 수 있습니다.
- **쇼핑몰.** 주소가 없으면 안내 페이지, 있으면 외부 링크. 설정 한 줄로 전환됩니다.
- **검색엔진 대응.** 페이지별 title·description·H1, canonical, Open Graph, 이미지 alt, sitemap.xml, robots.txt, 현재 위치 표시. 구조화 데이터는 Organization·WebSite(메인), BreadcrumbList(서브 전체), Person(대표이사), Article(공지·칼럼). 목록과 상세 내용은 모두 HTML에 들어 있어 스크립트 없이도 읽힙니다.
- **접근성.** 본문 바로가기, 키보드로 모든 메뉴 접근, 초점 표시, 모바일 메뉴 초점 가두기, 터치 영역 44px 이상, 동작 줄이기 대응.
- **성능.** 로고 788KB → 10KB(SVG), 대표 사진 1.6MB → 57KB, 이미지 지연 로딩, 영상 대체 이미지.

## 4. 구현하지 않은 기능

정적 사이트로 진행하기로 결정했기 때문에 서버가 있어야 하는 기능은 만들지 않았습니다.

| 기능 | 상태 | 대안 |
| --- | --- | --- |
| 관리자 페이지 (로그인, 콘텐츠 등록·수정, 파일 올리기, 노출 순서 변경) | 미구현 | `data/*.json` 을 수정하고 다시 빌드. 서버 구조는 [관리자_백엔드_설계.md](관리자_백엔드_설계.md) |
| 문의 내용 저장, 문의 관리, 관리자 메일 알림 | 미구현 | 방문자 메일 프로그램으로 전달. `inquiry.endpoint` 를 설정하면 전송 방식으로 전환 |
| 문의 첨부파일 | 전송 방식에서만 동작 | 메일 방식에서는 메일에 직접 첨부하도록 안내 |

| NewsArticle 구조화 데이터 | 적용하지 않음 | 언론 보도 페이지는 타 언론사 기사의 요약이라, 자사 기사로 표시하면 사실과 달라짐 |

### 확인하지 못한 것

- **문의 전송 방식.** 수신 주소가 없어 실제 전송은 시험하지 못했습니다. 메일 방식도 메일 프로그램이 실제로 열리는지는 브라우저 미리보기에서 확인할 수 없었습니다.
- **실제 기기와 다른 브라우저.** 크롬 계열 미리보기에서만 확인했습니다. 사파리, 삼성 인터넷, 실제 휴대폰은 확인하지 않았습니다.
- **지도.** 구글 지도가 주소를 정확한 위치로 표시하는지는 눈으로 확인하지 않았습니다.
- **외부 링크.** 언론 보도 원문 10건과 논문 주소 8건이 지금도 열리는지 확인하지 않았습니다.
- **GitHub Pages 배포 상태.** 로컬에서만 확인했고 아직 푸시하지 않았습니다.
- **검색 노출.** 구조는 갖췄지만 실제 검색 결과 노출은 보장할 수 없습니다.

## 6. 2차 보완 (2026-11-25, 「추가자료」 반영)

위 1~5번은 1차 작업 기준입니다. 「추가자료」 폴더와 고객사 현재 홈페이지(plbnb.com)를 반영해 아래와 같이 바뀌었습니다. 페이지 수는 95개에서 **115개**가 되었습니다.

| 영역 | 변경 |
| --- | --- |
| 특허 현황 | 등록 16건의 번호·명칭·출원일·등록일을 특허증 원본으로 대조해 수정. 과거 특허 5건 추가(헬리코박터, 비피도박테리움 인판티스, 체지방 저하 2건, 화장료). **특허증 이미지 16건 전부 게시**(PDF 1쪽을 이미지로 변환, 확대 보기 가능). 상세페이지에 특허권자 표시. 10-1452234 는 비공개 전환 |
| 개인정보 | 특허증 4건에 인쇄된 발명자 주민등록번호·자택 주소를 가림 처리 |
